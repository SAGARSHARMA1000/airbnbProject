# Airbnb Clone Project Guidelines & Best Practices

- **Visual Accuracy**: Ensure 100% adherence to Airbnb's signature typography, colors, padding, borders, and shadows.
- **Component Isolation**: Keep components clean, reusable, typed, and well-documented.
- **Responsive Layout**: Provide first-class experiences across mobile (<768px), tablet (768px - 1024px), and desktop (>1024px).
- **Interactive Modals**: All modals (Gallery Lightbox, All Amenities, All Reviews, Description, Share, Contact Host, Booking Confirmation) must support backdrop click, Escape key close, and smooth fade/scale transitions.
- **State Persistence**: Preserve user date and guest selections in state and update pricing calculations synchronously.
